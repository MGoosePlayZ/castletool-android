Castletool for Android

The original command-line tool, now built into a fleshed out Android app.

Castletool for Android is the official port of Castletool, built with flet.

Download the latest available APK from the [Releases page](https://github.com/MGoosePlayZ/castletool-android/releases) and install it on your Android device.
